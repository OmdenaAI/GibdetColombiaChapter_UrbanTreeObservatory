# Urban Tree Observatory - GIBDET Colombia Chapter

A web-based platform for monitoring, analyzing, and visualizing urban tree data in Colombia.

## Overview

The Urban Tree Observatory is an interactive application developed by the GIBDET Colombia Chapter to help monitor and analyze urban forest health. The platform provides tools for mapping tree locations, tracking health status, and generating insights about urban tree coverage.

## Features

- **Interactive Map**: Visualize tree locations with customizable map views
- **Tree Dashboard**: Monitor urban forest health metrics and statistics
- **Detailed Reports**: Generate detailed reports on tree health and distribution
- **User Authentication**: Secure login and registration system
- **Data Analytics**: Track trends and patterns in urban tree health

## Tech Stack

- **Frontend**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI, shadcn/ui
- **Maps**: Leaflet/React-Leaflet
- **Data Visualization**: Recharts

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-org/urban-tree-observatory.git
   cd urban-tree-observatory
   ```

2. Install dependencies:
   ```
   pnpm install
   ```

3. For development:
   ```
   pnpm dev
   ```

   Or for production:
   ```
   pnpm run build
   pnpm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Development

This project uses:
- TypeScript for type safety
- Next.js for server-side rendering and routing
- Tailwind CSS for styling
- shadcn/ui components based on Radix UI primitives
